Retrouver Héritage depuis une icône

Consultez les étapes ci-dessous pour ajouter Héritage à votre écran d’accueil.

Cette adresse locale fonctionne uniquement sur ce PC. Sur iPhone et iPad, utilisez l’adresse familiale publiée.

Sur iPhone ou iPad
  1. Ouvrez l’adresse privée dans Safari.
  2. Dans le menu de partage, choisissez « Sur l’écran d’accueil ».
  3. Si l’option apparaît, activez « Ouvrir comme app web », puis ajoutez Héritage.
  4. Ouvrez la nouvelle icône et préparez le hors connexion dans le Carnet.
Sur PC avec Microsoft Edge

Utilisez l’icône d’installation dans la barre d’adresse si elle apparaît, ou le menu … → Autres outils → Applications → Installer ce site en tant qu’application. Les libellés peuvent varier selon la version.

L’icône ne relie pas automatiquement votre Carnet et ne télécharge pas toutes les photos. Activez la synchronisation avec votre code personnel dans chacun de vos contextes Safari ou application. Vérifiez votre Carnet dans l’application ouverte ; exportez-le avant de changer de navigateur. Sur ce PC, gardez le serveur local lancé tant que le hors connexion n’est pas prêt.

Se déplacer dans l’arbre

Faites glisser l’arbre avec un doigt, ou maintenez le clic gauche de la souris sur une zone vide. La molette agrandit ou réduit l’arbre autour du pointeur. Touchez une carte pour sélectionner une personne. Utilisez + et − pour agrandir ou réduire l’arbre, puis le bouton de recentrage pour retrouver la sélection.

Les boutons de branche ouvrent la famille correspondante. Posez deux doigts dans l’arbre : écartez-les pour agrandir, rapprochez-les pour réduire. Si un défilement est déjà engagé, relevez les doigts avant de commencer le pincement.

Emporter mon arbre

Préparez une copie pour rouvrir cet arbre sans connexion, dans ce même navigateur. Les photos consultées seront conservées progressivement ; vous pouvez aussi les prendre toutes (environ 315 Mo).

Vérification de la disponibilité…

Une copie dans le navigateur ne remplace pas une sauvegarde. Sur iPhone et iPad, préparez la copie depuis l’adresse familiale publiée, dans chaque contexte Safari ou application utilisé.
