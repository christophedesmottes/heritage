# Héritage

Interface de consultation généalogique pour PC, iPhone et iPad.

Ce dépôt contient uniquement les fichiers de l’interface web. Les données généalogiques, photographies, notes et secrets ne font pas partie du dépôt.

Le service de données privé est configuré séparément. La publication de cette interface ne suffit pas à ouvrir l’accès à un arbre.

Publication GitHub Pages : branche principale, dossier racine.
