# Chronologie individuelle — Héritage 0.17.0

Sélectionner une personne dans l’arbre ou la recherche. Sa fiche contient la section **Chronologie** ; utiliser **Lire le portrait** pour la lire plus largement.

La ligne du temps réunit les événements personnels disponibles (naissance, résidence, profession, décès, etc.), les événements des unions et les naissances des enfants déclarés. Les événements datés sont classés chronologiquement ; ceux sans date interprétable figurent sous **Date non précisée ou non classable**. Les informations absentes ne sont pas inventées : aucun décès ni mariage n’est déduit.

Les qualificatifs « vers », « avant », « après » et les intervalles restent visibles. Lorsque leurs plages se chevauchent, l’ordre est indicatif. Une date non interprétable est affichée telle qu’importée dans la section séparée ; elle n’est pas effacée. Aucun âge précis n’est calculé à partir d’une date incertaine.

Pour les unions et enfants, les boutons ouvrent les fiches correspondantes. Les enfants présents dans plusieurs familles ne sont pas répétés automatiquement. Les qualifications de filiation disponibles sont affichées ; une naissance ne date pas une adoption ou l’entrée dans une famille.

Les photos/documents explicitement rattachés à un événement sont présentés sous celui-ci ; cliquer pour agrandir. Les portraits ajoutés près des naissances d’enfants sont des illustrations de ces personnes, pas des photographies de cette date. Leur contexte est indiqué. La galerie générale reste disponible dans Photographies.

**Sources de cet événement** ouvre les citations qui lui sont rattachées, avec titre, page et transcription disponibles. Les sources générales de la personne et des familles restent dans leur section distincte ; elles ne sont pas attribuées artificiellement à une date. Une citation ne constitue pas une preuve automatique de l’exactitude d’un événement.

Cette présentation utilise l’export chargé et les images déjà disponibles, sans changement des données ni service externe supplémentaire. Le hors connexion conserve les règles existantes : préparer l’arbre et les photos voulues. Aucun nouveau changement Supabase. Les étapes de synchronisation 0.15.2 restent à effectuer si elles ne le sont pas encore.

Après publication, vérifier sur vos appareils une fiche avec plusieurs unions/enfants, les événements sans date, les liens de navigation, les photos et les sources. Les corrections généalogiques se font dans MyHeritage avant un nouvel export.
